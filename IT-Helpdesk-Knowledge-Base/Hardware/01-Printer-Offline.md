# Printer Offline Troubleshooting

## Overview

A printer showing an "Offline" status cannot receive print jobs from the computer. This is one of the most common issues handled by IT Support teams.

---

## Environment

- Windows 10
- Windows 11
- USB Printer
- Network Printer

---

## Symptoms

- Printer shows "Offline."
- Documents remain in the print queue.
- Nothing prints.
- Error messages appear when printing.

---

## Possible Causes

- Printer is powered off.
- Loose USB or network cable.
- Printer disconnected from Wi-Fi.
- Incorrect default printer selected.
- Print Spooler service stopped.
- Driver problems.

---

## Troubleshooting Steps

1. Confirm the printer is powered on.
2. Check USB or network connections.
3. Ensure the printer is connected to Wi-Fi (if applicable).
4. Verify the correct printer is set as the default printer.
5. Clear the print queue.
6. Restart the Print Spooler service.
7. Update or reinstall the printer driver.
8. Print a test page.

---

## Resolution

Reconnect the printer, restart the Print Spooler if necessary, update the driver, and verify printing with a test page.

---

## Prevention

- Keep printer drivers updated.
- Avoid interrupting print jobs.
- Ensure stable network connectivity for wireless printers.
- Perform regular printer maintenance.
