# Lab 07 - Windows Services Investigation

## Objective

Explore the Windows Services management console and understand how services support Windows functionality.

---

## Steps Performed

1. Opened the Services management console using `services.msc`.
2. Located Print Spooler.
3. Located Windows Update.
4. Located Windows Audio.
5. Located DHCP Client.
6. Reviewed the status and startup type of each service.

---

## Observations

### Print Spooler

Status: Running

Startup Type: Automatic

### Windows Update

Status:

Startup Type: Disabled

### Windows Audio

Status: Running

Startup Type: Automatic

### DHCP Client

Status: Running

Startup Type: Automatic

---

## What I Learned

Windows Services run in the background and provide important functionality to Windows and installed applications.

The Services console can help IT Support technicians investigate problems when a required service is stopped or not functioning correctly.

---

No services were stopped, disabled, or modified during this lab.
