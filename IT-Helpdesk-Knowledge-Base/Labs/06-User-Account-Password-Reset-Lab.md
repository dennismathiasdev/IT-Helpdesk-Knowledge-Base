# Lab 06 - User Account & Password Reset

## Objective

Understand the basic Help Desk process for handling a user who cannot sign in because they have forgotten their password.

---

## Scenario

A user contacts the Help Desk and reports:

> "I forgot my password and cannot sign in."

---

## Important Note

This is a simulated Help Desk scenario created for portfolio and training purposes.

The personal Windows 11 computer used for this portfolio is not being presented as a corporate Active Directory environment.

---

## Information Gathering

Before making any changes, a Help Desk technician should verify:

1. The user's identity according to company procedures.
2. The username or account affected.
3. Whether the user receives an error message.
4. Whether the problem affects only one device.
5. Whether the account may be locked or disabled.
6. Whether the user recently changed their password.

---

## Troubleshooting Process

### Step 1 - Verify the User

Follow the organization's identity verification procedure before performing a password reset.

---

### Step 2 - Identify the Account

Confirm the correct username and determine which system manages the account.

Examples include:

- Active Directory
- Microsoft Entra ID
- Microsoft 365

---

### Step 3 - Check the Account Status

An IT technician should determine whether the account is:

- Active
- Locked
- Disabled
- Expired

---

### Step 4 - Reset the Password

If authorized, reset the user's password using the organization's approved identity-management system.

The technician should never record or expose the user's actual password in a ticket.

---

### Step 5 - Verify Access

Ask the user to sign in with the new credentials.

Confirm that the user can access the required system.

---

## Security Considerations

- Verify the user's identity before resetting a password.
- Never ask a user to send their password through email or chat.
- Never record passwords in Help Desk tickets.
- Follow the organization's password policy.
- Use approved administrative tools only.
- Escalate suspicious requests according to company procedures.

---

## Resolution

The user's identity was verified, the account was checked, and the password-reset process was completed according to the organization's procedures.

The user successfully regained access.

---

## What I Learned

Password-reset requests are not simply technical tasks. They also involve identity verification, security, documentation, and following organizational procedures.
