# Lab 01 - Task Manager Performance Investigation

## Objective

Learn how to use Task Manager to monitor system performance.

---

## Computer Information

Operating System:
Windows 11

RAM:
4 GB

---

## Steps Performed

1. Opened Task Manager using Ctrl + Shift + Esc.
2. Viewed the Processes tab.
3. Checked CPU usage.
4. Checked Memory usage.
5. Opened the Performance tab.
6. Reviewed CPU, Memory, Disk, and Network information.
