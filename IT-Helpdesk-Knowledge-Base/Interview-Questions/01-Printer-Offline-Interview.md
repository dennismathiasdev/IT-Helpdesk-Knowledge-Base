# Interview Question 01

## Question

A user reports that their printer is offline. How would you troubleshoot the issue?

---

## Sample Answer

I would first gather information by asking when the problem started, whether the printer is powered on, whether it is connected by USB or Wi-Fi, and whether other users are experiencing the same issue.

Next, I would check the printer status in Windows, verify it is the default printer, clear any stuck print jobs, restart the Print Spooler service if needed, and update or reinstall the printer driver if the issue persists.

Finally, I would print a test page to confirm that the problem has been resolved.
