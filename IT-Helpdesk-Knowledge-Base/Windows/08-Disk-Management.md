# Disk Management

## Overview

Disk Management is a Windows utility used to view and manage physical disks, partitions, and volumes.

IT Support technicians can use Disk Management to investigate storage and drive-related problems.

---

## How to Open Disk Management

Method 1:

Press:

Windows + X

Select:

Disk Management

Method 2:

Press:

Windows + R

Type:

diskmgmt.msc

Press Enter.

---

## Information Available

Disk Management can display:

- Physical disks
- Partitions
- Volumes
- Drive letters
- File systems
- Disk status
- Partition sizes

---

## Common IT Support Uses

- Investigate missing drives
- Check disk status
- Assign drive letters
- Identify partitions
- Investigate storage problems
- Verify whether Windows detects a disk

---

## Important Safety Considerations

Disk Management can make significant changes to storage devices.

IT technicians should not format, delete, shrink, or extend partitions without understanding the consequences.

Formatting or deleting the wrong partition can result in permanent data loss.
