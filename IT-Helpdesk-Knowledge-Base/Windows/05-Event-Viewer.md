# Event Viewer

## Overview

Event Viewer is a Windows tool used to review system, application, and security logs. It helps IT technicians investigate errors and diagnose system problems.

---

## How to Open

Method 1

Press the Windows key.

Search for:

Event Viewer

Method 2

Press:

Windows + R

Type:

eventvwr.msc

---

## Common Log Categories

- Application
- Security
- Setup
- System

---

## Event Levels

- Information
- Warning
- Error
- Critical

---

## When IT Support Uses It

- Investigate unexpected restarts
- Diagnose application crashes
- Review Windows errors
- Troubleshoot driver issues
- Analyze startup problems
