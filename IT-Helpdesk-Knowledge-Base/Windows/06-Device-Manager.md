# Device Manager

## Overview

Device Manager is a Windows tool used to view and manage hardware devices installed on a computer. It helps identify driver issues and hardware problems.

---

## How to Open

Method 1

Press:

Windows + X

Select:

Device Manager

Method 2

Press:

Windows + R

Type:

devmgmt.msc

---

## Common Device Categories

- Display adapters
- Disk drives
- Network adapters
- Bluetooth
- Keyboards
- Mice
- USB Controllers

---

## When IT Support Uses It

- Troubleshoot missing drivers
- Update drivers
- Disable or enable hardware
- Diagnose hardware failures
- Verify hardware installation

---

## Warning Signs

A yellow warning icon may indicate:

- Missing driver
- Corrupted driver
- Device error
