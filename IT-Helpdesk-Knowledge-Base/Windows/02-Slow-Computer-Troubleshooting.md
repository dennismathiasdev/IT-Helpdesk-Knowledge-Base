# Slow Computer Troubleshooting

## Overview

A slow computer is one of the most common issues reported to an IT Help Desk. Performance problems may be caused by software, hardware, startup programs, insufficient storage, malware, or outdated drivers.

---

## Common Symptoms

- Computer takes a long time to start.
- Programs open slowly.
- System freezes or becomes unresponsive.
- High CPU or memory usage.
- Slow internet despite a good connection.
- Delayed response when clicking applications.

---

## Possible Causes

- Too many startup applications
- Low available RAM
- Full hard drive or SSD
- Malware or viruses
- Windows updates running in the background
- Outdated drivers
- Failing hard drive
- Overheating

---

## Troubleshooting Procedure

### Step 1: Ask the User

- When did the issue begin?
- Is the computer always slow or only during certain tasks?
- Have you installed any new software recently?
- Is the problem affecting all users?

---

### Step 2: Check Task Manager

Open:

```
Ctrl + Shift + Esc
```

Review:

- CPU usage
- Memory usage
- Disk usage
- Startup applications

---

### Step 3: Disable Unnecessary Startup Programs

Task Manager → Startup Apps

Disable programs that are not required to start with Windows.

---

### Step 4: Check Disk Space

Open File Explorer.

Ensure the system drive has sufficient free space.

---

### Step 5: Scan for Malware

Run Microsoft Defender or another trusted antivirus scan.

---

### Step 6: Install Windows Updates

Settings → Windows Update

Install all recommended updates.

---

### Step 7: Restart the Computer

Restart the device and verify whether performance has improved.

---

## Resolution

Depending on the cause:

- Remove unnecessary startup applications.
- Free disk space.
- Remove malware.
- Update drivers.
- Replace failing storage devices if necessary.
- Upgrade RAM if the system does not meet workload requirements.

---

## Prevention

- Keep Windows updated.
- Avoid installing unnecessary software.
- Perform regular antivirus scans.
- Maintain adequate free storage space.
- Restart the computer regularly.
