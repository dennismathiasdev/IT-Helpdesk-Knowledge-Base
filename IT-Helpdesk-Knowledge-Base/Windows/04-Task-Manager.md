# Task Manager

## Overview

Task Manager is a Windows tool used to monitor running applications, background processes, system performance, and resource usage.

---

## How to Open

Method 1

Ctrl + Shift + Esc

Method 2

Right-click the Taskbar

Select:

Task Manager

---

## Main Tabs

- Processes
- Performance
- App History
- Startup Apps
- Users
- Details
- Services

---

## When IT Support Uses It

- Investigate slow computers
- End frozen applications
- Monitor CPU usage
- Check memory usage
- Identify high disk usage
- Monitor network activity
