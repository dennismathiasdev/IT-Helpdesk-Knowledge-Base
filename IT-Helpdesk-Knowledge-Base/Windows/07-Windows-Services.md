# Windows Services

## Overview

Windows Services are background processes that perform specific functions for Windows and installed applications.

IT Support technicians can use the Services management console to inspect service status and troubleshoot problems related to Windows features and applications.

---

## How to Open Services

Press:

```text
Windows + R
```

Type:

```text
services.msc
```

Press Enter.

---

## Important Service Information

The Services console provides information such as:

- Service Name
- Description
- Status
- Startup Type
- Log On As

---

## Common Services

### Print Spooler

Manages print jobs and communication between Windows and printers.

### Windows Update

Manages Windows update operations.

### Windows Audio

Manages audio functionality in Windows.

### DHCP Client

Helps the computer obtain network configuration from a DHCP server.

### Background Intelligent Transfer Service (BITS)

Supports background file transfers used by Windows and other applications.

---

## Common Startup Types

### Automatic

The service starts automatically when Windows starts.

### Automatic (Delayed Start)

The service starts automatically after other important startup processes.

### Manual

The service can be started when required.

### Disabled

The service cannot start until it is enabled.

---

## When IT Support Uses Services

- Troubleshoot printing problems
- Investigate Windows Update problems
- Diagnose audio problems
- Troubleshoot network-related services
- Investigate application dependencies

---

## Security and Safety

IT technicians should not randomly stop or disable Windows services.

A service should only be changed when there is a valid troubleshooting reason and the technician understands the potential effect.
