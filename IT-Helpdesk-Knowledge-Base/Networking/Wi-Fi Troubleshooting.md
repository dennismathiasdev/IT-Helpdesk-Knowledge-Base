# Wi-Fi Troubleshooting Guide

## Purpose

This guide provides step-by-step instructions for diagnosing and resolving common Wi-Fi connectivity issues on Windows computers.

## Symptoms

A user may experience one or more of the following:

- Unable to connect to Wi-Fi.
- Wi-Fi disconnects frequently.
- No internet access.
- Slow internet connection.
- Wi-Fi network not visible.

## Possible Causes

Common causes of Wi-Fi issues include:

- Wi-Fi is turned off.
- Airplane Mode is enabled.
- Incorrect Wi-Fi password.
- Weak Wi-Fi signal.
- Router is turned off.
- Internet Service Provider (ISP) outage.
- Outdated or corrupted network driver.

## Troubleshooting Steps

Follow these steps in order:

### Step 1: Check if Wi-Fi is enabled

- Ensure that Wi-Fi is turned on.
- Turn off Airplane Mode if it is enabled.

### Step 2: Confirm the correct Wi-Fi network

- Make sure the computer is connected to the correct wireless network.
- Re-enter the Wi-Fi password if necessary.

### Step 3: Restart the computer

- Restart the computer and try connecting again.

### Step 4: Restart the router

- Turn off the router.
- Wait for about 30 seconds.
- Turn it back on and wait for it to fully start.

### Step 5: Check if other devices can connect

- Try connecting another phone or laptop to the same Wi-Fi.
- If no device can connect, the issue may be with the router or Internet Service Provider (ISP).

### Step 6: Run Windows Network Troubleshooter

- Open Windows Settings.
- Select **System** > **Troubleshoot** > **Other troubleshooters**.
- Run the **Network and Internet** troubleshooter.

### Step 7: Contact the IT team or Internet Service Provider

If the problem continues after completing all the steps above, contact your IT department or your ISP for further assistance.

## Resolution

The issue is considered resolved when:

- The computer successfully connects to the Wi-Fi network.
- The user can browse the internet.
- The user confirms that the connection is stable.

---

## Prevention Tips

To reduce future Wi-Fi problems:

- Keep Windows updated.
- Restart your computer regularly.
- Keep your Wi-Fi drivers up to date.
- Avoid turning on Airplane Mode unless necessary.
- Stay within a good Wi-Fi signal range.
- Report recurring issues to the IT department.
