# ping Command

## Purpose

The `ping` command checks whether a computer can communicate with another device or website over a network.

---

## Syntax

```cmd
ping google.com
```

---

## Example

```cmd
ping google.com
```

Possible successful output:

```text
Reply from 142.250.xxx.xxx
```

---

## Common Uses

- Test internet connectivity
- Verify communication between devices
- Check if a server is reachable
- Troubleshoot network issues

---

## Common Errors

### Request timed out

The destination did not respond.

### Destination host unreachable

The destination cannot be reached.
