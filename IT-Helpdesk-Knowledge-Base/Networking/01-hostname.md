# hostname Command

## Purpose

The `hostname` command displays the name of the current computer.

---

## Syntax

```cmd
hostname
```

---

## Example

```cmd
hostname
```

Output:

```text
DESKTOP-XXXXXXX
```

---

## When IT Support Uses It

- Identify a user's computer
- Remote support
- Asset management
- Network troubleshooting

---

## Skills Demonstrated

- Command Prompt
- Windows Networking
- Device Identification
