# tracert Command

## Purpose

The `tracert` command shows the path that network traffic takes from your computer to another device or website.

---

## Syntax

```cmd
tracert google.com
```

---

## When IT Support Uses It

- Investigate slow internet connections
- Identify where a network connection fails
- Troubleshoot routing problems
- Verify network paths

---

## Example

```cmd
tracert google.com
```

The command displays each network hop between your computer and the destination.
