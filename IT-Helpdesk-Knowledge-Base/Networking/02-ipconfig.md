# ipconfig Command

## Purpose

The `ipconfig` command displays the current network configuration of a Windows computer.

---

## Syntax

```cmd
ipconfig
```

---

## Information Displayed

- IPv4 Address
- Subnet Mask
- Default Gateway

---

## When IT Support Uses It

- Troubleshoot internet connection problems
- Verify IP address assignment
- Confirm the default gateway
- Check network configuration

---

## Example

```cmd
ipconfig
```

Example output:

```text
IPv4 Address : 192.168.1.100
Subnet Mask  : 255.255.255.0
Default Gateway : 192.168.1.1
```
