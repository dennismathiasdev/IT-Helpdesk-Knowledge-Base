# Common Help Desk Tickets

## Ticket #001

**Date:** 03 August 2026

**Reported By:** Sarah Johnson

**Department:** Finance

**Issue:**

Unable to connect to the office Wi-Fi.

**Symptoms**

- Wi-Fi icon shows "No Internet".
- Unable to access company websites.
- Email not syncing.

**Investigation**

- Confirmed Wi-Fi was enabled.
- Airplane Mode was disabled.
- Another laptop connected successfully.
- The saved Wi-Fi password was incorrect.

**Resolution**

Removed the saved Wi-Fi profile.

Reconnected using the correct password.

Connection restored successfully.

**Status**

✅ Resolved
