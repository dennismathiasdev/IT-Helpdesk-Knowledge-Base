# Ticket #002 - Slow Computer

## Ticket Information

**Priority:** Medium

**Category:** Windows Performance

---

## User Report

The user reports that the computer has become very slow and applications take a long time to open.

---

## Information Gathered

- Asked when the issue started.
- Asked whether any software had recently been installed.
- Asked whether Windows had recently updated.
- Asked whether the issue affected all applications.

---

## Troubleshooting Steps

1. Opened Task Manager.
2. Checked CPU usage.
3. Checked Memory usage.
4. Checked Disk usage.
5. Reviewed Startup Apps.
6. Checked available storage.
7. Reviewed Windows Update status.
8. Restarted the computer.

---

## Resolution

The issue was investigated using standard Windows troubleshooting procedures. Performance improved after identifying unnecessary startup applications and confirming sufficient system resources.
